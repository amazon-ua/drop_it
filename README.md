# Навес из профтрубы — анализ и оптимизация каркаса

Навес над въездом (Харьков): 4 колонны, пролёт 5.45 м, шаг рядов колонн 4.60 м,
кровля из металлочерепицы 6.75 × 6.98 м, уклон 12°, проезд 4.00 × 2.90 м.
Цель — минимальная стоимость каркаса (металл + работа) при выполнении норм
без дополнительных запасов.

## Итог

| | Было (черновик 2026-ПР-480) | Стало |
|---|---:|---:|
| Итог сметы, грн | 236 820 | **179 873** (−56 947, −24 %) |
| Профильные трубы, грн | 76 029 | 41 004 |
| Масса металла, кг | 1227 | 760 |
| Деталей / швов, м / окраска, м² | 84 / 38 / 58 | 68 / 24 / 41 |

Принятая схема: 3 рамы (средняя опирается на Λ-образные боковые фермы в плоскостях рядов колонн),
подвеска у конька, без подкосов в коридоре и без связей по скатам. Сечения: колонны □100×60×4,
стропила □100×100×2,5, затяжки □60×60×2,5, обрешётка □35×35×2, раскосы боковых ферм □80×40×2,2,
нижний пояс □35×35×2, подвеска □25×25×2, стойка-вставка □80×40×2,5. Без позиций по «спеццене» —
183 842 грн. Подробности — в отчёте.

## Результаты

- `output/report.md` — отчёт: допущения, проверка черновика, принятое решение, сечения и
  проверки, ведомость, смета «было → стало», сравнение схем, чувствительность.
- `output/smeta_optimized.xlsx` — смета «было → стало», ведомость металла, детали, раскрой,
  проверки, все рассмотренные схемы, нагрузки.
- `output/navis_optimized.html` — чертёж оптимизированного каркаса (фасад, вид сбоку, план) с таблицами.
- `output/opt_results_*.json` — результаты перебора схем.

## Исходные данные (`input/`)

- `draft_drawing.html` — черновой проект 2026-ПР-480 («оптимальный по бюджету»);
- `koshtorys_navis_onovlenyi.xlsx` — смета (статьи расходов и суммы работ);
- `price_profile_tubes.xlsx` — прайс профильных труб, грн/м;
- `DBN_V.1.2-2_2006_zi_zminamy.pdf` — ДБН В.1.2-2:2006 «Навантаження і впливи» (зі змінами № 1, 2).

## Расчётная модель (`calc/`)

| Модуль | Назначение |
|---|---|
| `sections.py` | база сечений из прайса (t ≥ 2 мм, без некондиции), характеристики по средней линии с закруглениями |
| `fem.py` | пространственная стержневая МКЭ, геометрическая жёсткость, расчёт устойчивости |
| `model.py` | геометрия, варианты схем, нагрузки и сочетания по ДБН В.1.2-2 |
| `checks.py` | проверки ДБН В.2.6-198 (прочность, устойчивость, гибкость, стенки), узлы труб (EN 1993-1-8), прогибы, лунки (Бромс) |
| `costs.py` | металл по метражу, пластины, пересчёт статей сметы (окраска, швы, трудоёмкость) |
| `optimize.py` | подбор сечений по минимуму стоимости |
| `run_opt.py` | перебор схем (`all`; `normal` — без «спеццен»; `ch07` — ветер местности II) |
| `refine.py` | доводка лучших схем |
| `report.py` | формирование отчёта, xlsx и HTML |

Запуск:

```bash
pip install numpy scipy openpyxl
cd calc
python3 run_opt.py all      # ~1 ч на 4 ядрах
python3 refine.py all 8     # доводка лучших схем
python3 run_opt.py normal   # 4 лучшие схемы без аномально дешёвых позиций прайса
python3 run_opt.py ch07     # 4 лучшие схемы на ветер местности II (Ch = 0.70)
python3 report.py
```
