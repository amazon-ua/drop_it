# Навес из профтрубы — анализ и оптимизация каркаса

Навес над въездом (Харьков): 4 колонны, пролёт 5.45 м, шаг рядов колонн 4.60 м,
кровля из металлочерепицы 6.75 × 6.98 м, уклон 12°, проезд 4.00 × 2.90 м.
Цель — минимальная стоимость каркаса (металл + работа) при выполнении норм
без дополнительных запасов.

## Итог

Расчёт по стандартным позициям прайса (аномально дешёвые позиции < 50 грн/кг исключены),
геометрия — параллелограмм с косиной 2.87° и фактические отметки верха бетона колонн, как в черновике.

| | Было (черновик 2026-ПР-480) | Стало |
|---|---:|---:|
| Итог сметы, грн | 236 729 | **194 331** (−42 398, −17.9 %) |
| Профильные трубы, грн | 75 812 | 48 094 (без обрезков заказчика) |
| Масса металла, кг | 1226 | 828 |
| Деталей / швов, м / окраска, м² | 84 / 38 / 58 | 78 / 30 / 44 |

Принятая схема: 3 рамы (средняя опирается на Λ-образные боковые фермы в плоскостях рядов колонн),
подвеска + подкосы фермы у конька, без подкосов в коридоре и без связей по скатам. Сечения:
колонны □100×60×4, стропила □100×60×3, затяжки □60×60×2, обрешётка □35×35×2, раскосы боковых
ферм □60×60×2, нижний пояс □60×60×2, подвеска и подкосы фермы □20×20×2, стойка-вставка □60×60×3.
Боковые фермы — цеховые (пояс, раскосы и опорный столик свариваются в цеху, средняя рама
встаёт на столики стойками-вставками). Труба 35×35 продаётся только хлыстами 6 м (длины хлыстов — по полному прайсу `input/price_profile_tubes_full.xlsx`), поэтому обрешётины 6.98 м — из двух частей
5.49 + 1.49 м со стыком встык в пролёте, в 0.29 м от стропила рамы 3.
Торцевая обвязка □50×30×2 (на ребро) под обрешёткой в 175 мм от передней и задней кромки, без подкосов: её концы
держат карнизные обрешётины □50×30×2 на ребро (заодно поднимают карнизный край листа на 15 мм, как требует
металлочерепица) и коньковая □60×60×2 — чтобы консоли обрешётки выдерживали монтажника (ДБН В.1.2-2, п. 6.10;
без обвязки конец консоли перегружен втрое).
Колонны бетонируются на всю глубину лунки (низ на 10 см выше дна), без арматуры в лунках. Из обрезков заказчика 60×60×3 режутся оба раскоса одной боковой фермы, короткая часть коньковой обрешётины и стойки-вставки.
Сечения подобраны на ветер местности II и проверены для III. Подробности — в отчёте.

Проверена также схема с 5 поперечными фермами (облегчённые крайние фермы в 0.25 м от кромок,
лёгкая продольная балка по рядам колонн с консолями, шпренгель под средней фермой; `run_opt.py five`).
Лучший её вариант на той же базе — 202 280 грн, 862 кг, 64 детали, 32.9 м швов (+21.5 тыс. грн, +11.9 %
к принятому): обрешётка не облегчается (её определяет пролёт 2.3 м между фермами, а не консоль;
при продольном ветре она ещё и сжата — □40×40×2), колонны тяжелее (□100×100×2,8 по гибкости),
плюс 2 фермы, 2 балки и шпренгели — больше деталей, швов и монтажа. Схема не принята.

## Результаты

- `DECISIONS.md` — журнал решений: задание, ответы заказчика и ограничения, допущения, хронология цифр, принятое и отвергнутые варианты, открытые вопросы.
- `output/report.md` — отчёт: допущения, проверка черновика, принятое решение, сечения и
  проверки, ведомость, смета «было → стало», сравнение схем, чувствительность.
- `output/smeta_optimized.xlsx` — смета «было → стало», ведомость металла, детали, раскрой,
  проверки, все рассмотренные схемы, нагрузки.
- `output/navis_optimized.html` — чертёж каркаса (фасад, вид сбоку, план), проверки, заготовки с длинами реза, закупка по метражу и раскрой на хлысты 6 и 12 м, пластины и заглушки, раскладка и подрезка металлочерепицы. Документ для исполнителя — без сметы и её итога (цены труб — только в сравнении способов закупки).
- `output/navis_optimized.pdf`, `output/uzly.pdf` — те же документы в PDF (A4).
- `output/razbivka.html` / `.pdf` — разбивочный план лунок: привязка от опор ворот A и B, контрольные размеры и диагонали, порядок разбивки, отметки, глубины лунок и длины колонн (`python3 stakeout.py`).
- `output/otvet_ispolnitelyu.md`, `output/объяснение.pdf` — ответ на вопросы исполнителя (узел Б и порядок сварки, цеховая ферма, консоли обрешётки); PDF — `python3 explain_pdf.py`.
- `output/uzly.html` — чертежи узлов А (оголовок колонны), Б (опора средней рамы на столик фермы, с аксонометрией), В (конец фермы у колонны), общий вид цеховой боковой фермы, порядок изготовления и монтажа (цех / объект), швы и проверки.
- `output/opt_results_*.json` — результаты перебора схем.

## Исходные данные (`input/`)

- `draft_drawing.html` — черновой проект 2026-ПР-480 («оптимальный по бюджету»);
- `koshtorys_navis_onovlenyi.xlsx` — смета (статьи расходов и суммы работ);
- `price_profile_tubes.xlsx` — прайс профильных труб, грн/м;
- `DBN_V.1.2-2_2006_zi_zminamy.pdf` — ДБН В.1.2-2:2006 «Навантаження і впливи» (зі змінами № 1, 2).

## Расчётная модель (`calc/`)

| Модуль | Назначение |
|---|---|
| `sections.py` | база сечений из прайса (t ≥ 2 мм, без некондиции), характеристики по средней линии с закруглениями |
| `fem.py` | пространственная стержневая МКЭ, геометрическая жёсткость, расчёт устойчивости |
| `model.py` | геометрия, варианты схем, нагрузки и сочетания по ДБН В.1.2-2 |
| `checks.py` | проверки ДБН В.2.6-198 (прочность, устойчивость, гибкость, стенки), узлы труб (EN 1993-1-8), прогибы, лунки (Бромс) |
| `costs.py` | металл по метражу, пластины, пересчёт статей сметы (окраска, швы, трудоёмкость) |
| `optimize.py` | подбор сечений по минимуму стоимости |
| `run_opt.py` | перебор схем (`normal07` — основной: стандартные цены, ветер местности II; `all`/`ch07` — с «спеццен»ами, для сравнения; `five` — схема с 5 фермами) |
| `refine.py` | доводка лучших схем |
| `final_design.py` | окончательное решение (конструктивные корректировки узлов) и усилия в узлах |
| `nodes_drawing.py` | чертежи узлов |
| `tile_layout.py` | раскладка и подрезка металлочерепицы по скатам (косина 2.87°) |
| `report.py` | формирование отчёта, xlsx и HTML |
| `stakeout.py` | разбивочный план лунок → `output/razbivka.html` |
| `make_pdf.py` | PDF из HTML (`python3 make_pdf.py navis_optimized uzly razbivka`) |

Запуск:

```bash
pip install numpy scipy openpyxl
cd calc
python3 run_opt.py normal07     # основной перебор: стандартные цены, Ch = 0.70 (~25 мин на 4 ядрах)
python3 refine.py normal07 8     # доводка лучших схем
python3 run_opt.py all && python3 run_opt.py ch07   # для сравнения: с «спеццен»ами
python3 final_design.py
python3 nodes_drawing.py
python3 report.py
```
