Примечания

  • Нагрузки: ДБН В.1.2-2:2006 (зі змінами № 1, 2). Харків: S0 = 1600 Па, W0 = 430 Па; T = 50 років (γfm = 1.00 для снігу і вітру); експлуатаційні значення при η = 0.02 (γfe = 0.49 / 0.21).
  • Ветер: сечения подобраны для местности II (Ch = 0.70) и проверены для III (Ch = 0.40), z ≤ 5 м; навес — схема 11 дод. И, тип I, α = 12°: Ce = +0.62 / −1.04 / −0.88 / −0.08 (интерполяция 10°…20°), трение Cf = 0.04.
  • Снег: μ = 1 (схема 1 дод. Ж, α = 12°), дополнительно — снег на одном скате (п. 8.7).
  • Сталь: Ry = 230 МПа (С235 / S235JR), γc = 1.0, γn = 1.0 (СС1). Проверки по методике ДБН В.2.6-198; расчётные длины сжатых стержней — из расчёта на устойчивость всей пространственной модели.
  • Геометрия — параллелограмм, как в черновике: ряды колонн, конёк и карнизы параллельны боковым сторонам площадки, рамы и торцевые кромки кровли — передней кромке (косина 2.87°). Пролёт 5.45 м принят по перпендикуляру между рядами колонн (в плоскости рамы 5.457 м — в запас), шаг рядов рам 4.60 м (по разбивке 4.597).
  • Отметки — по разбивке черновика (площадка не выравнивается): верх бетона Л1 −0.06, П1 −0.09, Л3 −0.25, П3 −0.27; все отметки выше бетона (узлы +3.10, затяжка +3.00, конёк +3.68) одинаковы, разницу добирают длиной колонн — колонны заднего ряда на ~0.2 м длиннее и учтены в расчёте с фактической длиной.
  • Колонны бетонируются в лунки 300×300 глубиной 1.20–1.35 м (без изменений); заделка колонны в бетон уменьшена до 0.70 м (низ колонны заглушён, хомуты Ø8 сохранены).
